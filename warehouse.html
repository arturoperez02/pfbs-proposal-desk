📋 Print Settings — Follow Exactly
1. Click Print Label — a small window opens
2. Printer: DYMO LabelWriter
3. Paper/Label Size: 30334 Medium Multi-Purpose
4. Scale / Fit: Actual Size (100%) — NOT "Fit to page"
5. Margins: None / Minimum
6. Click Print ✓
⚠ If the barcode looks squished or tiny on the label — you have scaling on. Set to 100%.
If Browser Print doesn't scan, try "Print via Dymo" which uses the Dymo software directly
